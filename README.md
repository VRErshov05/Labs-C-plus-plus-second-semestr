# 💻 Лабораторные работы СПбПУ — ИКНК — ВШТИИ (2024)

## 📘 О проекте

Здесь собраны мои лабораторные работы по программированию, выполненные в рамках обучения в **Санкт-Петербургском политехническом университете (СПбПУ)**  
на направлении **Институт компьютерных наук и кибербезопасности (ИКНК)**,  
**Высшая школа технологий и искусственного интеллекта (ВШТИИ)**.

Работы охватывают основные курсы:
- **АИП** — Алгоритмизация и программирование  
- **ОПА** — Основы проектирования алгоритмов  
- **ООП** — Объектно-ориентированное программирование  

Все задания выполнены на языке **C++**.

---

## 🧩 Структура лабораторных работ

Каждая лабораторная работа имеет формат названия: Lab?s_?
где:  
- первая цифра — **номер семестра**,  
- последняя цифра — **номер лабораторной работы**.  

Пример:  Lab2_4 → 2-й семестр, лабораторная работа №4
